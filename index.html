    Einstellungen

    Kostenloses Konto auf opensky-network.org hebt das Tageskontingent an und könnte IP-basierte Blocks umgehen, die bei anonymen Anfragen auftreten.

    Manche Quellen blocken Cloudflares IP-Bereich speziell (siehe README). Ein zweiter Proxy auf anderer Infrastruktur (Deno Deploy, Code in deno-proxy.js im Repo) ist ein zweiter Versuch, wenn der erste bei einer bestimmten Quelle konsequent scheitert.

    Ganz ohne Key funktioniert ACARS bereits anonym, nur mit niedrigerem Rate-Limit. Ein kostenloser Feeder-Key (sobald du selbst ACARS/VDL2 oder ADS-B feedest) hebt das Limit an.

    Wird automatisch an den Kartenausschnitt angepasst (rein-/rauszoomen lädt mehr/weniger) — dieser Wert ist nur die Obergrenze dafür.
